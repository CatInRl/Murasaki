### T2.2 实现对话框系统并替换 36 处原生弹窗

**前置**：T0.1（lucide 图标）、T0.3（token）

**实施步骤**：
1. 新建 `src/stores/useDialogStore.ts`（Pinia）：管理对话框栈、Promise-based API（alert/confirm/prompt/conflict）
2. 新建 `src/components/DialogContainer.vue`：`<Teleport to="body">` 渲染
3. 实现 4 类型：
   - `alert`：单按钮（确定），信息/警告/错误变体
   - `confirm`：双按钮（取消/确认），可选危险变体（红色确认按钮）
   - `prompt`：双按钮 + 输入框，可选 placeholder/默认值/校验
   - `conflict`：三按钮（取消/重命名/覆盖），覆盖为危险变体
4. 按钮顺序严格对齐设计：取消在左，确认在右
5. 栈管理：同时只显示一个对话框（模态栈）
6. Escape 键等同点取消；打开时聚焦默认按钮（取消），prompt 聚焦输入框
7. 替换 36 处原生 `alert()/confirm()/prompt()`：
   - [App.vue](../src/App.vue) 21 处
   - [TreeNode.vue](../src/components/TreeNode.vue) 10 处
   - [AgentPanel.vue:114](../src/components/AgentPanel.vue#L114) → toast
   - [FileTree.vue](../src/components/FileTree.vue) → toast 或 confirm
   - [ImagePreviewModal.vue](../src/components/ImagePreviewModal.vue) → dialog.alert

**验收标准**：
- 全仓 grep `alert\(|confirm\(|prompt\(` 无原生弹窗（除对话框 store 内部）
- 单元测试：store 的 Promise API、栈管理
- E2E 测试：对话框视觉与 [ux-toasts-notifications.html:112-204](../murasaki-ui-design/pages/ux-toasts-notifications.html#L112) 一致
- 4 类型都能正确渲染和返回 Promise

   - 光标在当前段（空行分隔的连续文本行）→ 标记 `opacity: 0.4; font-size: 80%`（dim + 缩小）+ 渲染样式保留

5. 内容区域应用渲染样式：标题（字号+粗体）、粗体（`font-weight: bold`）、斜体（`font-style: italic`）、行内代码（背景+等宽字体）、引用块（左边框）、列表（项目符号 widget）、分隔线（块级 widget）
6. 监听 `view.state.selection` 变化 + `view.docView` 变化（防抖 50ms）
7. 大文档增量更新：仅重计算可见区域 ± buffer
8. Agent 提案 decoration 优先级高于 WYSIWYG 隐藏 decoration（提案覆盖范围不隐藏标记）

**验收标准**：

- E2E 测试：输入 `**bold**` 立即变粗体且看不到 `**`（光标离开后）
