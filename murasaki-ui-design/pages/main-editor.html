# Murasaki 快速入门
欢迎使用 Murasaki，一款轻量级的
本地 Markdown 编辑器。
## 核心特性
- 分屏编辑与实时预览
- 文件树管理与大纲导航
- 四套 Markdown 主题切换
- Mermaid 图表与 KaTeX 公式
## 开始使用
打开一个文件夹作为工作区，
即可开始管理你的 Markdown 文件。
```python
# 示例代码块
def hello():
print("Hello, Murasaki!")
```
