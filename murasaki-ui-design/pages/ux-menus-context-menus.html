Menus / 菜单

Murasaki 的菜单栏与右键菜单规范，统一使用弹出层面板、语义色板与清晰快捷键。

Menu Bar / 菜单栏

  • 新建文件 Ctrl+N
  • 打开文件 Ctrl+O
  • 打开文件夹 Ctrl+Shift+O
  • 保存 Ctrl+S
  • 另存为… Ctrl+Shift+S
  • 导出 HTML
  • 退出

File Tree / 文件树右键

  • 打开
  • 在新标签页打开
  • 重命名 F2
  • 剪切 Ctrl+X
  • 复制 Ctrl+C
  • 粘贴 Ctrl+V
  • 删除 Del
  • 在资源管理器中显示

Tab / 标签页右键

  • 关闭
  • 关闭其他
  • 关闭右侧
  • 复制路径
  • 在资源管理器中显示

Editor / 编辑器右键

  • 撤销 Ctrl+Z
  • 重做 Ctrl+Y
  • 剪切 Ctrl+X
  • 复制 Ctrl+C
  • 粘贴 Ctrl+V
  • 粘贴为纯文本
  • 全选 Ctrl+A
  • 查找 Ctrl+F
  • 在文件中查找 Ctrl+Shift+F

Agent Message / 智能体消息右键

  • 复制
  • 插入到光标处
  • 创建新文件
  • 清空对话

State Legend / 状态说明

默认
悬停 / Hover
禁用 / Disabled
