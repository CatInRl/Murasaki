项目提案书

本项目旨在为团队提供一款轻量、高效的本地 Markdown 编辑器，支持所见即所得编辑模式与 AI 辅助写作。

我们希望通过这次升级，让用户能够更加方便地管理和编辑文档。

本升级将显著降低文档管理与编辑的认知负担，使用户能够更专注于内容创作本身。

主要功能包括实时预览、文件树管理、多主题切换、Mermaid 图表以及 KaTeX 公式渲染。

核心特性

  • 分屏编辑与实时预览
  • 文件树管理与大纲导航
  • 四套 Markdown 主题切换
  • Mermaid 图表与 KaTeX 公式
